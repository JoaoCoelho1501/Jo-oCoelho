## 🚀 Featured Projects

### 📈 Retail Demand Forecasting — M5 Competition
Comparative evaluation of statistical, machine learning, deep learning, and foundation models for retail demand forecasting.

- Forecasting 216 product time series over a 28-day horizon.
- Evaluated AutoARIMA, AutoETS, XGBoost, NHITS, LSTM, Chronos, and TimeGPT.
- Compared models using RMSSE.
- Best reported result: AutoARIMAX (RMSSE: 0.7443).

**Technologies:** Python, Pandas, XGBoost, StatsForecast, NeuralForecast.

[View Project](https://github.com/JoaoCoelho1501/m5-retail-demand-forecasting)

### ⚙️ Chicago Crimes — Big Data Pipeline
Development of a data pipeline to process more than one million Chicago crime records using a Medallion-style architecture.

- Bronze, Silver, and Gold data layers.
- Data ingestion through a public API.
- Distributed processing and transformation with PySpark.
- Storage using HDFS and Parquet.

**Technologies:** Python, PySpark, HDFS, Parquet.

[View Project](https://github.com/JoaoCoelho1501/chicago-crimes-big-data-pipeline)

### 📊 Retail Sales Data Warehouse
Design and implementation of a retail data warehouse, from relational modelling to business intelligence reporting.

- Database normalization and relational modelling.
- SQL implementation and ETL processes.
- Star-schema dimensional modelling.
- Business metrics and Power BI dashboards.

**Technologies:** SQL, MySQL, Power BI, DAX.

[View Project](https://github.com/JoaoCoelho1501/retail-sales-data-warehouse)

### 🤖 Text Mining — Sentiment Analysis
Natural Language Processing project comparing traditional machine learning models with Transformer-based approaches.

- Text preprocessing and TF-IDF feature extraction.
- Classical machine learning classification.
- DistilBERT fine-tuning.
- Model evaluation and SHAP explainability.

**Technologies:** Python, NLTK, Scikit-learn, PyTorch, Hugging Face, SHAP.
